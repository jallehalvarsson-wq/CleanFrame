# New movies feed data

`new-se.json` is generated by the **New movies feed** GitHub Action from the
public JustWatch Sweden "new" pages for the apps in the CleanFrame dock.

- Workflow: `.github/workflows/new-movies-feed.yml`
- Scraper: `scripts/feed/scrape.py`
- Output branch: `feed`
- TV app URL:

```text
https://raw.githubusercontent.com/jallehalvarsson-wq/CleanFrame/feed/docs/feed/new-se.json
```

The `feed` branch is separate from `main`, so the daily JSON commits do not
clutter the main history. The app caches the last successful feed and filters
it to the providers currently on Home.

Do not edit `new-se.json` by hand. Run the workflow or the scraper instead.
