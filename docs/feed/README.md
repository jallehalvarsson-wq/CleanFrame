# Movie feed data

`new-se.json` and `popular-se.json` are generated by the **Movie feeds** GitHub
Action from the public JustWatch Sweden pages for the apps in the CleanFrame
dock.

- Workflow: `.github/workflows/new-movies-feed.yml`
- Scraper: `scripts/feed/scrape.py`
- Output branch: `feed`
- TV app URLs:

```text
https://raw.githubusercontent.com/jallehalvarsson-wq/CleanFrame/feed/docs/feed/new-se.json
https://raw.githubusercontent.com/jallehalvarsson-wq/CleanFrame/feed/docs/feed/popular-se.json
```

`new-se.json` contains recently added movies. `popular-se.json` contains the
provider movie catalogues, ordered by JustWatch popularity for the **Most
watched** panel. Neither file records playback on the TV.

The `feed` branch is separate from `main`, so the daily JSON commits do not
clutter the main history. The app caches the last successful copy of each feed
and filters it to the providers currently on Home.

Do not edit the JSON files by hand. Run the workflow or the scraper instead.
